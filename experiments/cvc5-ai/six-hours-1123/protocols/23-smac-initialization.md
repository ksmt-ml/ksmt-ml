# 23. Восстановление запуска SMAC после ошибки инициализации

В третьем раунде 20 первый ask выдал запрещённую маску 7. ConfigSpace содержит запрет этого вектора. `RandomInitialDesign` SMAC 2.4.0 создаёт копию пространства без запретов. Наш исполнитель остановил ветку до любой оценки вместо продолжения. Эта неисправность зафиксирована до запечатывания исходного теста. Исходные результаты и решение сохраняются. Два первых раунда не повторяются.

Повторяем только незапущенные оценки третьего SMAC. Используем исходные seed, train, validation, допустимые векторы и JVM лимит. Повторно используем сохранённые контрольные JVM с проверенными хешами и вычитаем из 270 с фактическое время исходного A/B и отказавшей инициализации. Исправленная случайная инициализация сэмплирует из исходного пространства с запретами. У всех категориальных уровней равные веса. Последующие предложения, обновления модели и критерии исходные. Валидация ограничена прежними 140 с и двумя кандидатами. Отказ конфигурации прослеживается без выполнения запрещённого вектора.

Восстановленный выбор запечатывается в отдельном файле до чтения любых закрытых исходов исполнительным скриптом. Для совпавшего вектора переиспользуем точные блоки исходного теста. Для нового вектора выполняем четыре отдельные парные реплики с A и E по исходным семействам. Число независимых семейств не увеличивается. Оценка показывает последствия технической ошибки отдельно от первичного сравнения. Ни один тестовый пакет не входит в поиск. Останов по общему дедлайну или по запечатанному расписанию.
