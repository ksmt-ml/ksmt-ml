## Файлы прогонов

[Скачать архивы измерений и контрольные суммы](https://github.com/ksmt-ml/ksmt-ml/releases/tag/cvc5-ai-2026-11). Имена семи основных архивов совпадают с именами каталогов серий. В них сохранены экспериментальные входы, измерения по задачам, неудачные прогоны и промежуточные результаты. Восстановить каталоги можно, распаковав архивы в этот каталог командой `tar --zstd -xf ИМЯ.tar.zst`. Для ночной серии дополнительно распакуйте `compressed-measurements.tar.zst` с 1176 журналами в JSON.gz. Архив `pilot.tar.zst` содержит первоначальные пробы. Целостность загрузки проверяется командой `sha256sum -c SHA256SUMS` в каталоге скачанных архивов.

Сторонние сборки, общедоступные архивы SMT-LIB и исходные checkout зависимостей загружаются отдельно. Версии, происхождение и условия экспериментов указаны в протоколах. В ветке сохранены изменения исходников KSMT и USVM, использованные в опытах. Скрипты записаны в том виде, в котором запускались на Linux, и содержат пути экспериментального стенда. Для запуска на другом хосте эти пути потребуется изменить.
