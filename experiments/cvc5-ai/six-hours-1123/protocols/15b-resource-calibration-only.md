# 15b. Раздельный запуск калибровки ресурса

Нативный 07 сохранил повторяемость статусов в обоих режимах. Калиброванный ресурс при этом дал 316 правильных ответов на 512 вместо 384 при времени. Перед возможным крупным живым тестом измеряем ровно замороженные 10 калибровочных блоков 15 и записываем отдельный итог. Перезапуск затем переиспользует эти блоки. При нехватке времени для полного живого теста калибровочный результат считается самостоятельной диагностикой переносимости. Не измеряем закрытые проекты только для заполнения оставшегося времени, если другой эксперимент лучше различает текущие объяснения.
