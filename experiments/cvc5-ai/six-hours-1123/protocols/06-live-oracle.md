# 06. Возвращаемые Java значения и покрытие вокруг FP/BV границы

Новый живой контроль на двух реализациях IEEE 754, вместе float и double. В каждой три сигнатуры: Java FP с floatToRawIntBits/doubleToRawLongBits, прямые предикаты FP, вход уже в виде битов. Все формы классифицируют знаки нулей, знаки бесконечностей, NaN и конечные числа по знаку, семь классов результатов. Представления сопоставимы по возвращаемым классам, внутренний путь и сложность формул могут отличаться. Ожидаемые семь классов подтверждаются выполнением Java на конкретных представителях. Живой USVM собирает все состояния до исчерпания очереди или 3000 шагов, без раннего стопа по покрытию. Для каждого разрешённого состояния измеряется, вернёт ли загруженный JVM метод тот же результат на конкретном свидетельстве.

cvc5 default, два отдельных переключателя, Z3 как контроль. Два seed, четыре JVM-повтора на разрядность, сбалансированный порядок и четыре ядра. Плечи сверяют нативную доставку и версии, отдельный прогрев. Первичные результаты — число достижимых классов, неверные свидетели, ошибки разрешения, неизвестные/таймауты, исключения шага, покрытие и stop reason. Время — диагностика. Сравнение эквивалентных форм не допускает переноса результатов на произвольный raw NaN payload. Стоп после замороженного расписания или до общего дедлайна.
