# Фаза 08 · повтор таймингов короткого holdout QF_LIA
В основном закрытом опыте все варианты решили по 48 из 48 повторов
на 24 экземплярах. Измеренная разница является разницей времени при
одинаковых ответах. Для оценки её масштаба повторяем весь фиксированный
набор уникальных конфигураций на том же holdout, с дополнительной
точной копией A′. Параметры и кап 7 с из lock сохраняются. Восемь
новых перемешанных блоков по каждому экземпляру, четыре физических ядра,
фиксированное зерно 184204. Ранжирование по новым измерениям не меняет
lock. Новые повторы не увеличивают число независимых семейств. Они
показывают только устойчивость времени и частоту редких сбоев.
